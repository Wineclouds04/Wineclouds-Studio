## 为什么选择 Wineclouds Studio

- **一个应用，一处集中**：窗口、状态、硬件、地图和外观设置不再散落在多个小工具里，打开就是完整工作台。
- **装完就能用**：自包含安装包，双击安装、直接开跑，不需要额外准备运行环境。
- **越用越顺手**：窗口缩略图、分组热键、配色方案都会记住你的习惯，下次启动自动还原。
- **安静又放心**：所有配置、统计与个性化设置都留在你自己的电脑上。
- **持续在打磨**：由独立开发者「酒酒的云」持续更新，版本迭代从不停摆。

## 功能亮点

| 功能 | 你能得到什么 |
| --- | --- |
| 窗口管理 | 把常用窗口变成实时缩略图固定在桌面上，点击即切换，还可置顶、调透明度、自动排列与分组热键循环。 |
| 多窗口同步 | 键鼠、点击、拖动与滚轮一次操作，多个目标窗口同步响应，多开场景省时省力。 |
| 硬件概览 | 一眼看清当前电脑的系统版本与主要硬件配置，机型、处理器、显卡、内存、磁盘、显示器、音频与网络一页读完。 |
| 区域检测 | 在屏幕上框出一块区域，颜色状态一变就循环响起提醒，适合长时间盯屏的场景。 |
| 区域预警 | 内置覆盖数千个星系与数十个区域的离线星际地图，支持搜索定位、路线规划、避让与跳桥、危险区提示、聊天情报与活动统计。 |
| 主题与调色盘 | 日光白、极夜黑或跟随系统，再叠加极简白、地海蔚蓝、樱语红粉、液态玻璃四套配色，颜值由你决定。 |
| 账号与更新 | 邮箱注册登录、会员等级与专属标识，并在应用内一键获取最新版本。 |

## 使用场景

- **多开同时在线**：多个客户端窗口一字排开，缩略图实时可见，热键一秒切换。
- **远程与长任务**：远程桌面、构建、下载或挂机任务的状态变化，用颜色提醒帮你盯着。
- **装机与设备盘点**：升级机器或排查配置时，快速看清这台电脑的真实底细。
- **星际作战计划**：看地图、算路线、避危险区、盯聊天情报，把情报面板放在手边。
- **桌面美化**：明暗主题配上四套调色盘与轻量动画，让工作台也有一点个人味道。

## 三步上手

1. 从[最新版 Release](https://github.com/Wineclouds04/Wineclouds-Studio/releases/latest)下载并运行安装包，国内用户也可前往 [Gitee 发布页](https://gitee.com/wang-jiaqi528/wineclouds-studio/releases)下载。
2. 打开首页，按需要进入窗口管理、区域检测或区域预警等工作区。
3. 到设置里挑一套主题、配色与语言，把它调成只属于你的工作台。
